# screen-qa —— 截图问 DeepSeek

把屏幕上的题目（选择题、数学题、表单、表格、任意文字）读成文字并让 DeepSeek 作答，
带多采样投票 + 交叉审核 + 置信度分级，答案自动进剪贴板。

## 何时用

- 用户给出一张题目截图/屏幕区域，想知道答案；
- 用户说"这个题怎么做/选哪个"并希望直接看到结论；
- 需要把图片里的题目文字提取出来再交给模型（DeepSeek 官方 API 不收图片）。

## 怎么调（脚本化，不用开界面）

```bash
# 对一张已经存在的图片作答（最常用）
python app.py --image <图片路径>

# 截全屏 → 识别 → 作答 → 打印
python app.py --cli

# 打开悬浮窗（手动/连续模式）
python app.py
```

输出末尾是 `## 最终答案`，正文含各次采样与置信度（🟢 高 / 🟡 中 / 🔴 存疑）。

## 首次配置

1. 填 Key：`config.json` 的 `api_key`，或环境变量 `DEEPSEEK_API_KEY`；
2. 需要更快/更省：`samples=1`、`verify=false`；
3. 需要更准：默认已是 `ocr_quality="high"`、`escalate=true`（分歧自动追加 2 次采样）。

## 注意

- 只把**识别出的文字**发给 API，截图本身不出本机；
- 圈选区域被其他窗口遮挡时会读到遮挡窗口的文字——先让题目窗口置顶；
- 置信度"存疑"时不要当成确定答案，如实告诉用户。
